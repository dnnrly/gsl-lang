# Tutorials

**Audience:** people who have grasped the [concepts](../concepts/graph-model.md) and want to *do* something.
**Prerequisite:** [Concepts](../concepts/graph-model.md) (or at least [Getting Started](../getting-started/README.md)).
**Next step:** [Cookbook recipes](../cookbook/README.md) — or start the [query tutorial](../../QUERY_TUTORIAL.md) now.

Two learning paths, both executable, both leading to the same depth:

## The flagship examples — "the long way round"

Five complete narratives, each a *problem → model → queries → derived views* story you can run end to end. They are the spine of this documentation — every tier links back to them.

| Example | The question it answers | What you'll learn |
|---|---|---|
| [01 — one graph, many views](../../examples/flagships/01-service-many-views/README.md) | "Retire this service — who breaks?" | Seven derived views from one 20-service model; the whole toolchain |
| [02 — architecture archaeology](../../examples/flagships/02-architecture-archaeology/README.md) | "We inherited a decade-old, undocumented monolith." | Reconstructing a model with evidence and provenance metadata |
| [03 — release prerequisites](../../examples/flagships/03-release-prerequisites/README.md) | "When can we promote?" | Edge dependencies — relationships *between edges* |
| [04 — financial relationships](../../examples/flagships/04-financial-network/README.md) | "What is the blast radius at the core?" | The language beyond software — financial network criticality |
| [05 — LLM-assisted modelling](../../examples/flagships/05-llm-assisted-modelling/README.md) | "Can an LLM draft a valid, serializable model?" | Modelling *with* an AI assistant; full-text prompt included |

The [flagship index](../../examples/flagships/README.md) explains how the suite is kept self-checked, and every result file in those directories is regenerated by `go test ./examples -run Flagship`.

## The query tutorial — the GQL learning path

When you have a graph, the interesting work is **selecting from it**. [QUERY_TUTORIAL.md](../../QUERY_TUTORIAL.md) is a step-by-step, ten-step path through GQL — the query/transformation language that derives views:

1. from **Step 1** — the mechanics of `gsl-query` — to
2. **Step 6** — subgraph + traversal, the blast-radius move — to
3. **Step 9** — named graphs and pipelines — to
4. **Step 10** — your own queries.

Every step is runnable (the examples use the canonical ordering rules you saw in [Canonical form](../concepts/canonical-form.md)), so you can type your way through it in an afternoon. The same material exists in reference form in [GQL_GUIDE.md](../../GQL_GUIDE.md) — the tutorial teaches, the guide answers.

## Which road to take

- **Want the full sweep of GSL first?** Run [01 — one graph, many views](../../examples/flagships/01-service-many-views/README.md), then take the query tutorial.
- **Iterate fast on a small model?** Start the [query tutorial](../../QUERY_TUTORIAL.md) directly — it needs nothing but the tools.
- **Ready to look something up?** Jump to [GQL_GUIDE.md](../../GQL_GUIDE.md) or the [cookbook](../cookbook/README.md).
